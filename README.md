# Optimal-PID-with-Simulink-and-GSA
This repository contains a MATLAB/Simulink implementation of the Gravitational Search Algorithm (GSA) for automatic PID controller tuning. Developed as part of my Master's Thesis in Electrical Engineering, the project optimizes controller parameters to improve system step response.

The original code was developed using MATLAB R2010a and has also been tested in MATLAB R2025a. The uploaded video shows how it can be used.

The Gravitational Search Algorithm (GSA) implemented in this project is based on the following publication:
